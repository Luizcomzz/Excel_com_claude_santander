# Horizonte_Invest 💵💰
Esse projeto foi desenvolvido com objetivo de explorar o uso do software excel para que o usuário possa observar qual a previsão de retorno dos investimentos em fundos imobiliários, além de orientar sobre quais tipos de fundos escolher com base no seu perfil 

---

## 🎯 Problema de Negócio

Uma pessoa quer decidir qual o melhor modelo de investimento para realizar em sua carteira, mas não sabe qual o mais vantajogoso para o seu perfil 

> **Pergunta central:**  Qual a melhor fundo para escolhar segundo o meu perfil de investidor?

---

## 💡 Impacto Esperado

Os resultados desta análise permitem à equipe de crédito:

- **Facilidade nos Investimentos** O usuário toma decisões mais assertivas e de maneira mais rapida, por não precisar pensar em quantos porcento investir em cada fundo
- **Constância nos Investimentos** Com o plano de investimento traçado o usuário, so precisa realizar os aportes sem preocupação

---

## 📋 Metodologia

### 1. Compreensão do problema de negócios
- Identificação do problema de negócio e formulação de hipóteses

### 2. Manipulação das planilhas
- Utilização de formulas para definir a regra do negócios

### 3. Teste de utilização
- Verificação se em cada mudança de parâmetro é apresentado o resultado esperado

### 4. Ajuste de design do aplicativo
- Ajuste de cor, recurso dos usuários
